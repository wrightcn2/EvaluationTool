# EvaluationTool

**Full-Stack Academic Evaluation Platform**  
*January 2024 – May 2024*

## Overview
EvaluationTool is a full-stack web application designed to streamline academic evaluations.  
It leverages **Angular** on the frontend and **Node.js/Express** with **MongoDB** on the backend.

## Tech Stack
- **Frontend:** Angular (Signals, control flow syntax, reactive forms, reusable components, routing)
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Tooling:** REST APIs, Nodemon for development

## Features
- Built reusable Angular components for modularity and maintainability
- Implemented client-side routing for smooth navigation
- Integrated REST APIs to connect frontend and backend
- Applied reactive forms for dynamic and validated user input
- Utilized modern Angular features (Signals, control flow syntax) for state management and cleaner code
